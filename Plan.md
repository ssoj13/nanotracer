# Plan.md — Tonemap toggle + view-independent splats

## Goals
- Единый цветовой пайплайн для 2D рендера и сплатов.
- Опция `-t/--tonemap` для включения/выключения тонемаппинга.
- Сплаты только view-independent (SH0), без view-dependent цветов.
- Без “заглушек”: корректная физика для TIR и согласованное поведение между рендером и сплатами.

## Почему сейчас расходится
- 2D рендер использует per-pixel нормализацию (`vec3_to_rgb`) вместо тонемаппинга.
- Сплаты всегда применяют `tonemap_srgb()` перед SH-фитом.
- SH3 пытается аппроксимировать зеркальные/рефрактивные материалы → “радуга”.
- `refract()` в рендерере при TIR возвращает фиктивный вектор, а в сплат-пайплайне используется другая логика.

## План работ

### 1) Вынести и унифицировать тонемаппинг
- Добавить модуль `src/color.rs` (или `src/tonemap.rs`) с функциями:
  - `tonemap_reinhard(Vec3) -> Vec3`
  - `linear_to_srgb(Vec3) -> Vec3`
  - `apply_tonemap(color, enabled: bool) -> Vec3`
- Использовать в обоих пайплайнах:
  - 2D рендер (перед записью в PNG)
  - сплат-сэмплинг (перед записью в SH0)
- Удалить per-pixel нормализацию из `vec3_to_rgb` или сделать её альтернативой, но не смешивать с тонемапом.

### 2) CLI опция `-t/--tonemap`
- В `src/main.rs` добавить флаг:
  - `--tonemap` (bool) и короткий `-t`.
- Пробросить в:
  - рендер (PNG)
  - сплат-экспорт
- Определить дефолт:
  - Предложение: `tonemap` включён по умолчанию (совместимо с viewer’ами).
  - Если надо сохранить старое поведение 2D — сделать дефолт `false` и явно включать.

### 3) View-independent сплаты (SH0)
- В `SplatConfig` добавить режим `view_independent: bool` или использовать `sh_degree = 0` как обязательное для сплатов.
- Логика генерации:
  - если view-independent: считать **один цвет на сплат** и записывать только `f_dc_*`, `f_rest_* = 0`.
  - цвет вычислять как **усреднение** по набору направлений (тот же `sh_samples`) через `trace_incoming`.
    - Это даёт физически корректный “усреднённый” результат без SH-артефактов.
- Оставить `--sh-degree` только для future/debug, но по умолчанию сплаты генерить как SH0.

### 4) Согласовать физику рефракции
- Устранить заглушку в `renderer::refract`:
  - при TIR возвращать отражённый луч (physically correct), а не `Vector3::new(1,0,0)`.
- Использовать **один и тот же** `refract()` и `reflect()` для рендера и сплат:
  - либо экспортировать из `renderer` в общий модуль, либо переместить в `geometry`/`ray`/`math`.

### 5) Валидация
- Сравнить 2D и сплаты при `--tonemap` on/off, `--sh-degree 0`:
  - красный должен совпасть по насыщенности.
- Сцена со стеклом:
  - отсутствие радужных артефактов (SH0, view-independent).
- Проверить viewer-совместимость (bevy_gaussian_splatting).

## Затрагиваемые файлы
- `src/main.rs` (CLI флаг `--tonemap` + режим сплат)
- `src/utils.rs` (замена/упрощение `vec3_to_rgb`)
- `src/splat/sampler.rs` (view-independent режим, применение общего tonemap)
- `src/renderer.rs` (TIR + применение общего tonemap в output)
- новый `src/color.rs` (общие функции)

## Тесты
- Юнит-тесты на тонемап (детерминированные входы → ожидаемые выходы).
- Smoke-тест: `cargo run --release -S test.ply --tonemap` и открытие в viewer.
- Smoke-тест 2D: `cargo run --release --tonemap` сравнить с дефолтным.
